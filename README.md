# استوديو رجل العصا | Stickman Studio Arabic

مشروع Android مستقل بمعرّف الحزمة `com.bassim.stickmanstudio`، وواجهة عربية RTL، والحد الأدنى Android 7.0 (API 24).

## ما تتضمنه هذه الحزمة حاليًا
- مشروع Android/Kotlin قابل للبناء.
- مساحة رسم ثنائية الأبعاد خفيفة باستخدام Android Canvas.
- رسم شخصيات رجل عصا متعددة وإضافتها وحذفها.
- تحريك تمهيدي للأطراف عبر إطار زمني بسيط.
- التحكم بالإطار ومعاينة الحركة.
- حفظ واستعادة بيانات المشهد محليًا على الهاتف.
- GitHub Actions لإنتاج APK تجريبي عند دفع الملفات أو تشغيل Workflow يدويًا.

## حالة المشروع
هذه **حزمة تأسيسية قابلة للتوسعة وليست إصدارًا نهائيًا مكتمل الميزات**. لم تُنفّذ بعد: محرر المفاصل بالسحب، نظام keyframes الكامل، مكتبة الأصول، تعدد المشاهد، الكاميرا، استيراد الصوت ومزامنته، وتصدير MP4. يجب تطوير هذه الوحدات واختبارها قبل وصف التطبيق بأنه مكتمل.

## البناء
يتطلب Android Gradle Plugin 8.7.3 وJDK 17 وAndroid SDK 35. في GitHub Actions يتم البناء على خادم GitHub.
